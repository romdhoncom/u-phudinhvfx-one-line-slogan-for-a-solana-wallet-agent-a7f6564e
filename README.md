# One-Line Slogan for a Solana Wallet Agent

One slogan of at most twenty words for a Solana wallet agent, entered on make.fun. The slogan: "Your wallet, finally fluent in plain English — and Solana."

## Run it

```sh
node main.ts
```

This writes the slogan to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
